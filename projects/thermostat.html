Software Design and Engineering

Thermostat System

An embedded thermostat application designed for Raspberry Pi that monitors environmental temperature, manages heating and cooling states, and interfaces with hardware components including GPIO buttons, LEDs, a temperature sensor, and an LCD display.

Original Artifact Refined Artifact GitHub Repository

Professional Review

This artifact demonstrates my growth in software design and engineering through the refinement of an embedded system originally developed to run on Raspberry Pi. The project uses a state-machine approach with operating modes for off, heat, and cool, while continuously monitoring temperature and updating system output.

In the enhanced version, I improved the system’s reliability and maintainability by introducing structured logging, stronger error handling around sensor and serial communication, and clearer internal organization. These changes preserved the original functionality while bringing the codebase closer to professional software engineering standards.

Original Artifact

The original version successfully integrated multiple hardware components and demonstrated a functioning thermostat system, but it relied heavily on basic print-based debugging and lacked stronger resilience for real-world execution.

Enhancements

  • Implemented structured logging for better monitoring and debugging
  • Added error handling around critical hardware interactions
  • Improved readability and maintainability through better code organization
  • Replaced scattered debug output with centralized logging practices

Reflection

This project taught me the difference between writing code that works and writing code that remains stable, observable, and maintainable over time. It reflects my ability to improve an existing system without disrupting its intended behavior.
