Databases and Full-Stack Development

Client Server Development

A database-driven dashboard application built for Grazioso Salvare that uses MongoDB, Python, and dashboard visualization tools to search, manage, and display animal shelter records.

Original Artifact Refined Artifact View Source Code

Professional Review

This artifact demonstrates my ability to design and enhance a full-stack, database-driven application. The original dashboard allowed users to search and view animal shelter data from the Austin Animal Center using MongoDB and a Python-based interface.

In the enhanced version, I improved the application by strengthening CRUD operations, introducing structured database connectivity, adding authentication and input validation, and expanding the user interface with better filtering, charts, and map-based presentation. These improvements reflect a stronger integration between backend data management and front-end usability.
